## 왜 배열 메서드를 배워야 할까?

JavaScript를 처음 배울 때 배열을 다루려면 `for` 루프부터 시작하는 게 일반적이다. 그런데 실제 프로젝트 코드를 보면 `for` 루프 대신 `map`, `filter`, `reduce`를 훨씬 자주 쓴다. 오늘 이 세 가지를 제대로 정리해 봤다.

---

## 1. `map` — 배열을 변환할 때

`map`은 배열의 각 요소를 변환해서 **새로운 배열**을 만든다. 원본 배열은 건드리지 않는다.

```js
const prices = [1000, 2000, 3000];

// 모든 가격에 부가세 10% 추가
const pricesWithTax = prices.map((price) => price * 1.1);

console.log(pricesWithTax); // [1100, 2200, 3300]
console.log(prices);        // [1000, 2000, 3000] ← 원본 그대로
```

React에서 리스트를 렌더링할 때 `map`을 엄청 많이 쓰기 때문에, 꼭 익혀둬야 한다.

---

## 2. `filter` — 조건에 맞는 것만 골라낼 때

`filter`는 콜백 함수가 `true`를 반환하는 요소만 모아서 **새로운 배열**을 만든다.

```js
const products = [
  { name: "노트북", stock: 0 },
  { name: "마우스", stock: 5 },
  { name: "키보드", stock: 0 },
  { name: "모니터", stock: 2 },
];

// 재고가 있는 상품만 필터링
const inStock = products.filter((product) => product.stock > 0);

console.log(inStock);
// [{ name: "마우스", stock: 5 }, { name: "모니터", stock: 2 }]
```

---

## 3. `reduce` — 배열을 하나의 값으로 줄일 때

`reduce`는 처음에는 좀 어렵게 느껴지지만, 배열 전체를 순회하면서 **누적값**을 만들어가는 구조다.

```js
const cartItems = [
  { name: "커피", price: 4500, qty: 2 },
  { name: "샌드위치", price: 6500, qty: 1 },
  { name: "케이크", price: 5000, qty: 3 },
];

// 장바구니 총 금액 계산
const total = cartItems.reduce((acc, item) => {
  return acc + item.price * item.qty;
}, 0); // 0은 초기값

console.log(total); // 4500*2 + 6500*1 + 5000*3 = 30500
```

`reduce(콜백, 초기값)` 형태로 쓰는데, 초기값을 꼭 넣어주는 습관을 들이자. 빈 배열에서 초기값 없이 `reduce`를 쓰면 에러가 난다.

---

## 세 메서드를 함께 쓰기

이 메서드들은 **체이닝(chaining)**해서 함께 쓸 수도 있다.

```js
const orders = [
  { item: "아메리카노", price: 4000, paid: true },
  { item: "라떼", price: 5000, paid: false },
  { item: "에스프레소", price: 3500, paid: true },
];

// 결제 완료된 주문의 총 금액
const paidTotal = orders
  .filter((order) => order.paid)
  .map((order) => order.price)
  .reduce((acc, price) => acc + price, 0);

console.log(paidTotal); // 7500
```

---

## 느낀 점

`for` 루프로도 똑같이 구현할 수 있는데 왜 이걸 쓰나 싶었는데, 직접 써보니까 **의도가 훨씬 명확하게 드러난다**는 게 느껴졌다. "이 배열을 변환한다", "이 조건으로 필터한다", "합계를 구한다"가 코드만 봐도 바로 읽힌다. 특히 세 메서드를 체이닝했을 때 코드가 마치 문장처럼 읽히는 게 신기했다. `reduce`는 아직 좀 낯설지만 자주 써보면 익숙해질 것 같다.
