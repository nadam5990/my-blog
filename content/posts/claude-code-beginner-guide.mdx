## Claude Code가 뭔가요?

한 줄로 설명하면 이렇습니다:

> **터미널에서 쓰는 AI 코딩 도우미**

평소에 ChatGPT나 Claude 웹사이트에서 코드를 물어봤다면, 그건 "AI한테 물어보고 → 내가 직접 복붙"하는 방식이었죠.

Claude Code는 달라요. AI가 **직접** 내 프로젝트 파일을 읽고, 코드를 수정하고, 터미널 명령어도 실행해줍니다. 중간에 사람이 복붙할 필요가 없어요.

쉽게 비유하면 이렇습니다:

- 기존 방식 → 요리 레시피를 AI한테 물어보고 **내가 직접 요리**
- Claude Code → AI가 옆에 서서 **직접 같이 요리**

---

## 설치하기

Node.js가 설치되어 있다면 터미널에 딱 한 줄만 입력하면 됩니다:

```bash
npm install -g @anthropic-ai/claude-code
```

설치 후 처음 실행할 때 Anthropic 계정으로 로그인하면 끝입니다.

> **Node.js가 없다면?** [nodejs.org](https://nodejs.org)에서 LTS 버전을 받아 설치하세요.

---

## 처음 시작하는 법

### 1. 프로젝트 폴더로 이동

```bash
cd 내-프로젝트-폴더
```

### 2. Claude Code 실행

```bash
claude
```

이러면 이런 화면이 뜹니다:

```
Claude Code v1.x.x
Type your message or / for commands

>
```

이제 여기에 **하고 싶은 것을 우리말로 그냥 적으면** 됩니다.

## 실제로 어떻게 쓰나요?

### 예시 1 — 버그 고쳐달라고 하기

```
> 로그인 버튼 누르면 에러가 나는데 고쳐줘
```

Claude Code가 알아서 에러 관련 파일들을 찾아보고, 문제를 분석하고, 코드를 수정합니다.

---

### 예시 2 — 새 기능 만들어달라고 하기

```
> 게시물 검색 기능 만들어줘. 제목이랑 본문에서 검색되게 해줘
```

관련 파일들을 스스로 파악하고, 필요한 코드를 작성하고, 연결까지 해줍니다.

---

### 예시 3 — 모르는 코드 설명해달라고 하기

```
> 이 프로젝트 구조가 어떻게 되어있는지 설명해줘
```

프로젝트 전체를 훑어보고 폴더 구조, 주요 파일, 데이터 흐름을 알기 쉽게 설명해줍니다.

## 꼭 알아야 할 기본 명령어

Claude Code 안에서 `/`로 시작하는 명령어를 쓸 수 있습니다.

| 명령어 | 하는 일 |
|--------|---------|
| `/help` | 사용 가능한 명령어 목록 보기 |
| `/clear` | 대화 내용 초기화 (새로 시작할 때) |
| `/compact` | 긴 대화를 요약해서 토큰 아끼기 |
| `/exit` | Claude Code 종료 |

## 초보자가 자주 하는 실수

### ❌ 실수 1 — 너무 짧게 말하기

```
# 나쁜 예
> 고쳐줘

# 좋은 예
> 회원가입 폼에서 이메일 형식 검사가 안 되는 버그 고쳐줘
```

AI도 맥락이 필요합니다. **구체적으로** 말할수록 정확한 결과가 나옵니다.

---

### ❌ 실수 2 — 한 번에 너무 많이 시키기

```
# 나쁜 예
> 로그인 기능이랑 회원가입이랑 프로필 수정이랑 비밀번호 찾기 다 만들어줘

# 좋은 예
> 먼저 로그인 기능만 만들어줘
```

한 번에 하나씩 시키면 오류도 적고 결과 확인도 쉽습니다.

---

### ❌ 실수 3 — 결과를 확인 안 하기

AI가 코드를 작성해도 **직접 실행해서 확인**하는 습관이 중요합니다. Claude Code는 대부분 잘 작동하지만, 항상 100%는 아니거든요.

## 유용한 사용 패턴

### 패턴 1 — 계획 먼저 물어보기

큰 작업 전에 계획을 먼저 세우게 하면 실수가 줄어들어요:

```
> 사용자 인증 기능을 추가하려고 해. 
  어떤 파일을 수정하고 어떤 순서로 만들어야 하는지 계획만 먼저 알려줘
```

계획을 보고 "OK, 그대로 진행해줘" 하면 됩니다.

---

### 패턴 2 — 막혔을 때 원인 분석

```
> npm run build 하면 이 에러가 나는데 왜 그런지 설명하고 고쳐줘:
  [에러 메시지 붙여넣기]
```

에러 메시지를 그대로 붙여넣으면 원인 분석부터 해결까지 해줍니다.

---

### 패턴 3 — 코드 리뷰 받기

```
> 내가 작성한 코드 리뷰해줘. 
  개선할 점이나 버그 가능성 있는 부분 알려줘
```

시니어 개발자한테 코드 리뷰 받는 느낌으로 쓸 수 있습니다.

---

## 비용은 얼마나 드나요?

Claude Code는 **사용한 만큼 내는 방식(종량제)** 입니다.

일반적인 사용 패턴 기준으로:
- 간단한 버그 수정 1건 → 약 $0.01~0.05
- 새 기능 추가 1건 → 약 $0.05~0.30
- 하루 열심히 쓰면 → 보통 $1~3 수준

처음엔 Anthropic이 크레딧을 제공하기 때문에 **먼저 무료로 충분히 써보고** 결제 여부를 결정할 수 있습니다.
