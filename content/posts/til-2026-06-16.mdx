## 웹 페이지가 어떻게 데이터를 가져올까?

유튜브를 열면 추천 영상 목록이 뜨고, 날씨 앱을 열면 현재 기온이 나타난다. 이 데이터들은 모두 어디선가 **받아온** 것이다. 바로 서버에 HTTP 요청을 보내서 데이터를 가져오는 것인데, 브라우저에서 이 작업을 가장 쉽게 할 수 있게 해주는 게 **Fetch API**다.

## fetch()의 기본 사용법

`fetch(url)`은 해당 URL에 GET 요청을 보내고 **Promise**를 반환한다. 응답을 받으면 `.json()`으로 JSON 데이터를 파싱할 수 있다.

```js
fetch("https://jsonplaceholder.typicode.com/posts/1")
  .then((response) => response.json())
  .then((data) => {
    console.log(data.title); // 포스트 제목 출력
  })
  .catch((error) => {
    console.error("요청 실패:", error);
  });
```

Promise 체인이 복잡하게 느껴진다면, 지난번에 배운 `async/await`를 함께 쓰면 훨씬 깔끔하다.

```js
async function getPost() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/posts/1");

    if (!response.ok) {
      throw new Error(`HTTP 오류: ${response.status}`);
    }

    const data = await response.json();
    console.log(data.title);
  } catch (error) {
    console.error("요청 실패:", error);
  }
}

getPost();
```

> **포인트**: `fetch()`는 404나 500 같은 HTTP 오류가 와도 Promise를 **거부(reject)하지 않는다**. 그래서 `response.ok`를 직접 확인해야 한다. 실제 네트워크 오류(인터넷 연결 끊김 등)에서만 `catch`가 실행된다.

## POST 요청 보내기

데이터를 서버에 **전송**할 때는 두 번째 인자로 옵션을 넘긴다.

```js
async function createPost() {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      title: "새 포스트",
      body: "내용입니다",
      userId: 1,
    }),
  });

  const newPost = await response.json();
  console.log("생성된 포스트 ID:", newPost.id);
}

createPost();
```

- `method`: `"GET"`, `"POST"`, `"PUT"`, `"DELETE"` 등을 지정한다.
- `headers`: 요청 헤더를 설정한다. JSON을 보낼 때는 `Content-Type: application/json`이 필수다.
- `body`: 서버에 보낼 데이터. 객체는 `JSON.stringify()`로 문자열로 변환해야 한다.

## 느낀 점

처음에 fetch가 Promise를 반환한다는 게 헷갈렸다. 특히 `response.ok`를 따로 체크해야 한다는 점은 의외였다 — 오류 응답을 받아도 자동으로 실패하지 않는다니! 직접 콘솔에서 JSONPlaceholder API를 불러보며 `.ok`, `.status`, `.json()` 등을 하나씩 찍어보니 훨씬 이해가 빨랐다. 앞으로 날씨 앱이나 To-do 앱 같은 프로젝트를 만들 때 Fetch API를 바로 써볼 수 있을 것 같아서 설렌다.
