오늘 Claude Code를 이용해서 블로그를 만들었다. 코드를 직접 짜진 않았지만, AI가 만들어준 파일들을 보면서 웹이 어떻게 돌아가는지 어렴풋이 감을 잡게 됐다.

## HTML — 뼈대

HTML은 웹 페이지의 **구조**를 잡는 언어다.

집으로 비유하면 **기둥, 벽, 방**에 해당한다. 여기에 제목이 있고, 여기에 본문이 있고, 여기에 버튼이 있다 — 이런 걸 정의하는 게 HTML의 역할이다.

```html
<h1>안녕하세요</h1>
<p>블로그에 오신 걸 환영합니다.</p>
<button>더 보기</button>
```

내가 만든 블로그에서는 `app/page.tsx` 같은 파일이 이 역할을 한다. React(JSX)로 작성하지만, 결국 브라우저에 전달될 때는 HTML로 변환된다.

---

## CSS — 옷

CSS는 HTML로 만든 뼈대에 **디자인을 입히는** 언어다.

같은 집이라도 벽지 색깔, 가구 스타일에 따라 분위기가 완전히 달라지듯이, CSS가 바로 그 역할을 한다.

```css
h1 {
  color: indigo;
  font-size: 2rem;
}

button {
  background-color: indigo;
  border-radius: 8px;
  padding: 8px 16px;
}
```

내 블로그에서는 **Tailwind CSS**를 썼다. CSS를 직접 쓰는 대신 `className="text-xl font-bold text-indigo-500"` 처럼 미리 만들어진 클래스를 조합하는 방식이다. 처음엔 낯설었는데, 빠르게 디자인을 잡을 수 있어서 편리하다.

다크모드도 CSS의 영역이다. `.dark` 클래스가 붙으면 색상 변수가 바뀌고, 페이지 전체가 어두운 테마로 전환되는 것도 CSS 덕분이다.

---

## JavaScript — 움직임

JavaScript는 웹 페이지를 **살아 움직이게** 만드는 언어다.

HTML이 뼈대, CSS가 외모라면 JavaScript는 **근육과 신경**이다. 버튼을 클릭하면 뭔가 일어나고, 입력창에 타이핑하면 결과가 바뀌는 것 — 이게 전부 JavaScript다.

```javascript
button.addEventListener('click', () => {
  alert('버튼이 클릭됐어요!')
})
```

내 블로그에서 JavaScript가 쓰인 부분:

- **다크모드 토글** — 버튼 클릭 시 테마 전환
- **검색 기능** — 타이핑할 때마다 실시간으로 게시물 필터링
- **모바일 메뉴** — 햄버거 버튼 클릭 시 메뉴 열고 닫기

React와 Next.js도 결국 JavaScript(TypeScript)로 만들어진 도구다.

---

## 세 가지의 관계를 한 줄로

| 언어 | 역할 | 비유 |
|------|------|------|
| HTML | 구조 | 집의 뼈대 |
| CSS | 디자인 | 인테리어 |
| JavaScript | 동작 | 전기, 수도, 동작 |

## 느낀 점

Claude Code로 블로그를 만들면서 코드를 직접 한 줄도 안 쳤는데, 오히려 코드가 어떻게 생겼는지, 왜 이런 구조인지를 더 자연스럽게 이해하게 됐다.

AI가 만들어준 파일을 보면서 "아, 이 부분이 버튼 디자인이구나", "이 부분이 클릭했을 때 동작이구나" 하고 읽게 되더라.

코딩을 배우는 새로운 방법을 찾은 것 같다. 🙂
