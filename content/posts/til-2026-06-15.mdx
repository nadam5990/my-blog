요즘 웹 사이트는 스마트폰, 태블릿, 노트북 등 다양한 기기에서 열린다. 그런데 PC 화면에 꽉 차는 레이아웃을 그냥 스마트폰으로 보면 어떻게 될까? 글씨가 엄청나게 작아지거나, 가로 스크롤이 생겨서 읽기 불편해진다. 이 문제를 해결해 주는 게 바로 **CSS 미디어 쿼리(Media Query)**다.

## 미디어 쿼리란?

미디어 쿼리는 "화면 너비가 얼마 이하일 때 이 스타일을 적용해!" 처럼, **특정 조건을 만족할 때만** CSS 규칙을 적용하는 문법이다.

```css
/* 기본 스타일 (모든 화면) */
.container {
  display: flex;
  gap: 16px;
}

/* 화면 너비가 768px 이하일 때 */
@media (max-width: 768px) {
  .container {
    flex-direction: column; /* 세로로 쌓기 */
  }
}
```

위 코드에서 `.container`는 기본적으로 가로로 나란히 배치된다. 하지만 화면 너비가 768px보다 좁아지면(주로 모바일 환경) 자동으로 세로로 쌓이도록 바뀐다.

## 자주 쓰는 브레이크포인트

**브레이크포인트(breakpoint)**는 레이아웃이 바뀌는 기준 너비를 말한다. 보통 아래 값을 많이 쓴다.

| 기기 | 브레이크포인트 |
|------|---------------|
| 모바일 | ≤ 480px |
| 태블릿 | ≤ 768px |
| 노트북 | ≤ 1024px |
| 데스크톱 | 1025px 이상 |

## 실제 예시: 카드 목록

```css
.card-list {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* PC: 3열 */
  gap: 20px;
}

@media (max-width: 768px) {
  .card-list {
    grid-template-columns: repeat(2, 1fr); /* 태블릿: 2열 */
  }
}

@media (max-width: 480px) {
  .card-list {
    grid-template-columns: 1fr; /* 모바일: 1열 */
  }
}
```

PC에서는 카드가 3개씩 나란히, 태블릿에서는 2개씩, 스마트폰에서는 1개씩 쌓이게 된다. 브라우저 창을 직접 줄여보면 레이아웃이 바뀌는 게 눈에 보여서 신기하다.

## `min-width` vs `max-width`

- `max-width`: "이 너비 이하일 때" → 큰 화면 기준으로 짜고 모바일 예외 처리 (Desktop First)
- `min-width`: "이 너비 이상일 때" → 모바일 기준으로 짜고 큰 화면을 확장 (Mobile First)

요즘은 **모바일 퍼스트(Mobile First)** 접근이 권장된다. 작은 화면부터 시작해서 큰 화면으로 레이아웃을 넓혀가는 게 더 자연스럽기 때문이다.

```css
/* Mobile First 방식 */
.card-list {
  grid-template-columns: 1fr; /* 기본: 모바일 1열 */
}

@media (min-width: 481px) {
  .card-list {
    grid-template-columns: repeat(2, 1fr); /* 태블릿 이상: 2열 */
  }
}

@media (min-width: 769px) {
  .card-list {
    grid-template-columns: repeat(3, 1fr); /* PC 이상: 3열 */
  }
}
```

## 느낀 점

미디어 쿼리를 배우기 전에는 "반응형 웹은 어렵겠지..."라고 생각했는데, 알고 보니 `@media` 한 줄로 시작되는 간단한 문법이었다. 물론 실제 프로젝트에서 모든 화면을 완벽히 대응하는 건 더 많은 고민이 필요하겠지만, 기본 원리 자체는 생각보다 직관적이었다. 이제 브라우저 DevTools에서 화면 크기를 바꿔가며 직접 테스트해 보는 습관을 들여야겠다!
