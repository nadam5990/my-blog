오늘은 JavaScript에서 자주 쓰이는 **구조 분해 할당(Destructuring Assignment)** 을 제대로 공부했다.
React 코드를 보다 보면 `const { name, age } = user` 같은 문법이 자주 나오는데, 막상 뜻을 물어보면 설명하기 어려웠다. 오늘 드디어 제대로 이해했다!

## 구조 분해 할당이란?

배열이나 객체에서 필요한 값을 꺼내어 변수에 한 번에 담는 문법이다.
기존 방식과 비교해 보면 차이가 확실하다.

```js
// 기존 방식 — 하나씩 꺼내야 해서 번거롭다
const user = { name: "지수", age: 24, city: "서울" };
const name = user.name;
const age = user.age;

// 구조 분해 할당 — 한 줄로 끝!
const { name, age } = user;
console.log(name); // "지수"
console.log(age);  // 24
```

## 배열도 같은 방식으로

객체뿐만 아니라 배열도 구조 분해 할당이 된다. 변수 이름을 자유롭게 정할 수 있다는 게 장점이다.

```js
const colors = ["빨강", "파랑", "초록"];

// 기존 방식
const first = colors[0];
const second = colors[1];

// 구조 분해 할당
const [first, second] = colors;
console.log(first);  // "빨강"
console.log(second); // "파랑"
```

## 기본값 설정도 가능하다

값이 없을 때를 대비해 기본값을 지정할 수 있다.

```js
const { name, role = "방문자" } = { name: "민준" };
console.log(role); // "방문자" — 객체에 role이 없으니 기본값 사용
```

## React에서 특히 자주 쓴다

`useState` 훅의 반환값도 배열 구조 분해 할당이다. 알고 보면 매일 쓰고 있었던 것!

```js
// useState가 [상태값, 변경함수] 배열을 반환하고,
// 구조 분해 할당으로 바로 변수에 담는 것이다
const [count, setCount] = useState(0);
```

함수의 매개변수에서도 바로 쓸 수 있다.

```js
function greet({ name, age }) {
  return `안녕하세요, ${age}살 ${name}님!`;
}

greet({ name: "서연", age: 22 }); // "안녕하세요, 22살 서연님!"
```

## 느낀 점

구조 분해 할당은 문법이 낯설어서 처음에는 "도대체 이게 뭐지?" 싶었는데, 알고 나니 오히려 없으면 불편할 것 같다. 특히 React를 쓸 때 props를 받는 컴포넌트 코드가 훨씬 깔끔해진다는 걸 느꼈다. 앞으로는 객체나 배열에서 값을 꺼낼 때 자연스럽게 구조 분해 할당을 떠올릴 수 있을 것 같다. 작은 문법 하나가 코드 가독성을 이렇게 높여준다는 게 신기하다.
