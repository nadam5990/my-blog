오늘은 JavaScript에서 배열을 다룰 때 가장 자주 쓰이는 세 가지 메서드, **`map`**, **`filter`**, **`reduce`** 를 제대로 공부해봤다. 처음엔 `for` 루프로 다 해결하려 했는데, 이 메서드들을 쓰면 코드가 훨씬 짧고 의도가 명확해진다는 걸 깨달았다.

## map — 배열의 모든 요소를 변환하기

`map`은 배열의 각 요소에 콜백 함수를 적용해서 **새 배열을 반환**한다. 원본 배열은 그대로 유지된다.

```js
const prices = [1000, 2500, 4200];

// 모든 가격에 10% 할인 적용
const discounted = prices.map((price) => price * 0.9);
console.log(discounted); // [900, 2250, 3780]
```

객체 배열에서 특정 필드만 뽑아내고 싶을 때도 아주 유용하다.

```js
const users = [
  { name: "지수", age: 22 },
  { name: "민준", age: 30 },
];

const names = users.map((user) => user.name);
console.log(names); // ["지수", "민준"]
```

## filter — 조건에 맞는 요소만 걸러내기

`filter`는 콜백이 `true`를 반환하는 요소만 모아서 **새 배열을 반환**한다.

```js
const scores = [45, 82, 67, 91, 55];

// 70점 이상만 필터링
const passed = scores.filter((score) => score >= 70);
console.log(passed); // [82, 91]
```

`map`과 `filter`는 체이닝(chaining)해서 함께 쓸 수 있다.

```js
const products = [
  { name: "노트북", price: 1200000, inStock: true },
  { name: "마우스", price: 35000, inStock: false },
  { name: "키보드", price: 89000, inStock: true },
];

// 재고 있는 상품의 이름만 추출
const availableNames = products
  .filter((p) => p.inStock)
  .map((p) => p.name);

console.log(availableNames); // ["노트북", "키보드"]
```

## reduce — 배열을 하나의 값으로 줄이기

`reduce`는 처음엔 좀 어렵게 느껴지지만, 배열 전체를 **단일 값(숫자, 문자열, 객체 등)으로 집계**할 때 쓴다.

```js
const cart = [3000, 8500, 12000, 500];

// 장바구니 합계 계산
const total = cart.reduce((acc, price) => acc + price, 0);
console.log(total); // 24000
```

`acc`는 누적 값(accumulator), 두 번째 인자 `0`은 초깃값이다. 매 반복마다 `acc`에 현재 요소를 더해 최종 합계를 만든다.

## 세 메서드 비교 한눈에 보기

| 메서드 | 목적 | 반환값 |
|--------|------|--------|
| `map` | 각 요소 변환 | 같은 길이의 새 배열 |
| `filter` | 조건에 맞는 요소 선택 | 더 짧을 수 있는 새 배열 |
| `reduce` | 전체를 하나로 집계 | 단일 값 (어떤 타입도 가능) |

---

## 느낀 점

처음엔 `for` 루프가 더 익숙해서 굳이 새 문법을 배울 필요가 있나 싶었다. 그런데 `filter().map()` 처럼 체이닝하면 "재고 있는 것 골라서 → 이름만 뽑아" 라는 의도가 코드 자체에서 읽히는 게 신기했다. 특히 React에서 목록을 렌더링할 때 `map`이 거의 필수라는 걸 알고 나니, 이걸 이해하는 게 얼마나 중요한지 실감했다. `reduce`는 아직 낯설지만 합계·카운트·그룹핑 등 다양한 곳에 쓸 수 있으니 꾸준히 연습해봐야겠다.
