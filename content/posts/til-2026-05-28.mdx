오늘은 CSS Flexbox에 대해 제대로 공부했다. 예전에는 요소를 가운데 정렬하려고 `margin: auto`나 `position: absolute`를 이리저리 조합하다가 결국 포기한 적이 많았는데, Flexbox를 쓰니까 훨씬 간단하다는 걸 깨달았다.

## Flexbox가 뭔가요?

Flexbox(Flexible Box Layout)는 요소들을 **한 방향으로 정렬**하는 데 특화된 CSS 레이아웃 방식이다. 부모 요소에 `display: flex`를 한 줄만 추가하면, 자식 요소들이 자동으로 가로로 나란히 배치된다.

```css
.container {
  display: flex;
}
```

이것만으로도 자식 요소들이 가로로 정렬된다. 신기하지 않나?

## 가장 많이 쓰는 속성들

### 정렬 방향 바꾸기

```css
.container {
  display: flex;
  flex-direction: column; /* 세로 방향으로 쌓기 */
}
```

기본값은 `row`(가로)이고, `column`으로 바꾸면 세로로 쌓인다.

### 가운데 정렬 — 드디어 쉬워졌다!

```css
.container {
  display: flex;
  justify-content: center; /* 주축(가로) 기준 가운데 */
  align-items: center;     /* 교차축(세로) 기준 가운데 */
  height: 100vh;
}
```

이 세 줄만 쓰면 화면 한가운데에 요소를 딱 갖다 놓을 수 있다. 예전에 이걸 몰라서 얼마나 고생했는지…

### 요소 간격 균등하게 배분하기

```css
.nav {
  display: flex;
  justify-content: space-between; /* 양쪽 끝에 딱 붙이고 나머지 균등 배분 */
}
```

네비게이션 바 만들 때 정말 유용하다. 로고는 왼쪽, 메뉴는 오른쪽에 두고 싶을 때 `space-between` 하나면 끝난다.

### 자식 요소가 남은 공간을 채우게 하기

```css
.sidebar {
  width: 200px;
}

.main-content {
  flex: 1; /* 남은 공간을 모두 차지 */
}
```

사이드바 + 메인 콘텐츠 레이아웃을 만들 때 `flex: 1`이 정말 편리하다.

## 실전 예제: 카드 목록 만들기

```html
<div class="card-list">
  <div class="card">카드 1</div>
  <div class="card">카드 2</div>
  <div class="card">카드 3</div>
</div>
```

```css
.card-list {
  display: flex;
  flex-wrap: wrap;   /* 공간이 부족하면 다음 줄로 넘기기 */
  gap: 16px;         /* 카드 사이 간격 */
}

.card {
  flex: 1 1 200px;   /* 최소 200px, 남은 공간 균등 분배 */
  padding: 16px;
  border: 1px solid #ddd;
  border-radius: 8px;
}
```

`flex-wrap: wrap`과 `gap`을 같이 쓰면 반응형 카드 목록을 별도의 미디어 쿼리 없이도 간단히 만들 수 있다.

## 느낀 점

Flexbox를 배우기 전에는 레이아웃 잡는 게 가장 두려웠다. `float`을 쓰면 clearfix 문제가 생기고, `inline-block`은 이상한 공백이 생기고… 그런데 Flexbox는 직관적이라서 머릿속으로 그림을 그리면서 코드를 짤 수 있다는 느낌이 든다.

특히 **가운데 정렬**이 이렇게 쉬울 수 있다는 게 충격이었다. 앞으로 레이아웃 작업할 때는 Flexbox를 먼저 떠올려야겠다. Grid도 곧 공부해봐야지!
